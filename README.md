# AI-Powered Phishing Email Detection

A Machine Learning based cybersecurity web application that detects phishing emails using Python, Scikit-learn, and Streamlit.

## Features
- Detect phishing emails
- Machine Learning prediction
- TF-IDF vectorization
- Real-time web app
- Safe/Phishing classification

## Technologies Used
- Python
- Streamlit
- Scikit-learn
- Pandas
- NumPy

## Run Locally ##Author

```bash
pip install -r requirements.txt
streamlit run web_app.py
